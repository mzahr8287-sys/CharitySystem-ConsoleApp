# Charity Management System 🕊️

**Charity Management System** هو تطبيق 콘솔 (Console Application) تم بناؤه باستخدام لغة **C#** ومنصة **.NET 10.0** لإدارة عمليات التبرعات والأنشطة داخل المؤسسات الخيرية بطريقة بسيطة ومنظمة.

## 🚀 الميزات الرئيسية

* **نظام تسجيل الدخول وإنشاء الحسابات:** يدعم التطبيق إنشاء حسابات جديدة للمستخدمين وإدارة الجلسات وصلاحيات المسؤولين.
* **إدارة التبرعات:** تتبع التبرعات النقدية والعينية (السلع والأدوات) وحساب إجمالي العناصر المتاحة تلقائيًا.
* **إدارة المتبرعين والأنشطة:** واجهات مخصصة لإضافة وعرض بيانات المتبرعين والأنشطة الخيرية المختلفة.
* **تقارير مالية وعينية:** يعرض التطبيق لوحة تحكم فورية للمستخدم توضح الرصيد المالي الحالي وإجمالي عدد التبرعات العينية المخزنة.

## 🛠️ التقنيات المستخدمة

* **اللغة:** C#
* **المنصة:** .NET 10.0 (الأحدث)
* **نوع التطبيق:** Console Application

## 📂 الهيكل البرمجي للمشروع

يتكون المشروع من الهيكل الأساسي التالي:
* `Program.cs`: الملف الرئيسي الذي يحتوي على نقطة انطلاق البرنامج والـ Main Loop الخاصة بالتحكم في القوائم.
* `DonationServes`: الطبقة المسؤولة عن معالجة وإدارة العمليات والبيانات الخاصة بالتبرعات.
* `AccountManager`: إدارة بيانات الحسابات، التحقق من الهوية، والتحكم في أرصدة المستخدمين.
* **طبقة العرض (Views):** تشمل `ViewDonar`, `ViewActivity`, `ViewDonation`, `ViewReport` لفصل واجهة المستخدم عن منطق العمل.

## 💻 طريقة التشغيل

### المتطلبات المسبقة
* تثبيت حزمة التطوير **.NET 10 SDK** أو أحدث.
* أي بيئة تطوير تدعم سي شارب مثل **Visual Studio 2022** أو **VS Code**.

### خطوات التشغيل عبر Terminal
1. قم بعمل استنساخ (Clone) للمستودع:
   ```bash
  https://github.com/mzahr8287-sys/CharitySystem-ConsoleApp.git
   ```
2. انتقل إلى مجلد المشروع:
   ```bash
   cd CharitySystem-ConsoleApp
   ```
3. قم بتشغيل المشروع مباشرة:
   ```bash
   dotnet run
   ```
